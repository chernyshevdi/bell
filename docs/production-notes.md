# Допущения и что нужно для прода

- **Вебинары → продукты:** на the-chat.io продукт не указан. Дашевский → Invest, Либерманы → Tech, Пешкин и Архипова → Unlimited, вебинар Tech → Tech.
- **Пятый вебинар** («Тёмная сторона AI») со страницы The Bell.Tech, а не с the-chat.io: он идёт сегодня и есть разовое участие за 1 990 ₽. Шесть вебинаров участников без дат не брал.
- **Витрина:** один продукт за раз (слайд) по дате; три материала продукта и широкая карточка «ещё по подписке». Вид и цвета блока мои, такого блока на сайте нет.
- **Invest и «Новости и аналитика»:** цены с сайта не сняты, онлайн-оплаты в демо нет (кнопки нет, строка «скоро будет можно»). Вебинар Дашевского (Invest) без кнопки.
- Пробный тариф Tech в демо открывает вебинары Tech сразу (на сайте только со 2-го месяца).
- Ротацию в демо считает браузер; контракт серверной ротации описан ниже.
- Фото материалов и портреты спикеров принадлежат The Bell и The Chat; на проде их отдаёт CMS.

## Что нужно, чтобы выкатить на прод
1. **Оплата.** Сейчас мок. На проде шаг оплаты заменяется hosted-чекаутом провайдера (на thebell.io он уже есть: `thebell.io/checkout/<hash>`); данные карты не должны проходить через наш фронт. Нужны вебхук об успешной оплате, письмо и активация подписки, учёт автопродления.
2. **Серверная ротация.** CMS отвечает на `GET /cms/blocks/:id` объектом `{ settings, content, serverTime }`. Если есть `serverTime`, приложение считает «сегодня» по нему (ротация и статусы вебинаров). Купленные продукты клиент пропускает сам: сервер не знает о подписке пользователя.
3. **Админка и хранилище.** Сейчас редактирование через JSON. Нужны интерфейс правки, сохранение, права доступа, предпросмотр.
4. **Подписки и доступ.** Список купленного хранится в `localStorage` (демо). Нужна авторизация и проверка подписки на сервере.
5. **Юридическое.** Ссылки на оферту и политику реальные; нужны маркировка (иноагент, 18+) и согласие на автопродление по требованиям.
6. **Права на изображения** и аналитика (воронка: показ блока → клик → тарифы → оплата → успех).
