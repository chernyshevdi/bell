# Сценарий видео (≤ 5 минут, запись экрана)

Подготовка: демо открыто в двух окнах (десктоп и узкое окно ~390 px), DevTools закрыты, файл `app/public/cms/blocks/showcase.json` открыт в редакторе. Запуск `npm start` (правка файла видна после сохранения).

| Время | Что показываю | Что говорю |
|---|---|---|
| 0:00–0:20 | главная целиком | задача: два блока в сетке конструктора, из них путь до оплаты |
| 0:20–1:30 | десктоп, затем мобильное окно: витрина, вебинары, «Показать ещё», лента на мобильном | блоки выглядят как часть сайта, не баннеры; на мобильном лента со свайпом |
| 1:30–2:30 | витрина → «Выбрать тариф» → тарифы Tech (USD/RUB) → оплата: пустая форма, отказная карта, потом успех → два экрана успеха | оплата мок, но весь UX; на проде здесь hosted-чекаут |
| 2:30–3:30 | «админка»: в `showcase.json` меняю `startDate` или порядок `slideIds` — витрина переключается; меняю заголовок и цену слайда; в `webinars.json` меняю `startsAt` | редакция правит один файл блока, формат `{settings, content}` у всех блоков; сбой одного блока не роняет страницу |
| 3:30–4:30 | допущения и чего нет | вебинары привязал к продуктам сам; Invest и «Новости» без оплаты; оплата мок; серверная ротация описана контрактом, в демо считает браузер |
| 4:30–5:00 | итог | что сделал, что понадобится для прода |

Заранее проверить: тестовые карты `4242 4242 4242 4242` (успех) и `4000 0000 0000 0002` (отказ); после покупки очистить `localStorage` (`bell.subscriptions`), чтобы витрина снова показывала Tech.
